# 参与项目

欢迎提交客户端兼容性、动作观感、文档和网页可访问性改进。

1. Issue 请说明操作系统、Codex 版本、复现步骤和预期表现。
2. 不要提交账户令牌、个人配置、聊天记录、Library 链接或账号内宠物 ID。
3. 新增图片、音频和视频时说明来源、制作方式和许可；不接受来源不明的下载素材或应用源码。
4. 修改安装器或图集后运行 README 中的校验和测试命令。
5. 代码贡献采用 MIT；同人美术按 `assets/LICENSE.md` 的独立条件处理，第三方角色权利保留。

请将原生客户端能力与网页演示能力分别描述。不要把网页花饰按钮宣传成可直接替换原生按钮的补丁。
